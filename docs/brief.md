# Golf Cart Optimization — prototype brief

## Purpose

See every golf cart on a course, its battery level, and whether it is connected to the charging (power) system.

## Prototype scope (v0)

- Fleet list and simple course map with mock carts
- Battery percent and low-battery highlighting
- Power connection: plugged in vs not plugged in
- Local API serving cart data (no real vehicle hardware yet)

## Out of scope for now

- Native Android / iOS / Windows apps
- Real GPS or charger hardware
- User accounts and multi-course tenancy
- Production cloud hosting

## Later

- Same API for mobile and desktop clients
- Live telemetry from carts / chargers
- Cloud or on-course local server
